# P02-T11 — Collection / Repeater

## هدف
Repeater در Template که روی collectionهایی مثل projects/team حلقه می‌زند.

## پیش‌نیاز
- Projects/Team؛ Template/Document schema

## پرامپت اجرا

```
طبق Collection/Repeater و Data Binding پایه عمل کن (بدون فرمول پیشرفته فاز 03).

تسک: Repeater را در document-schema + editor + renderer پیاده کن.

الزامات:
1) تحلیل + تسک‌لیست.
2) نود repeater با source (مثلاً projects) و قالب کارت داخلی.
3) رندر سمت preview و PDF از داده PostgreSQL Business.
4) UI انتخاب source و ویرایش کارت؛ Gate اگر ماژول منبع قفل است.
5) docs/schema؛ تست با چند پروژه.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
