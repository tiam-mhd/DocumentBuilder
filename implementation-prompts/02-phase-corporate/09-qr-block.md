# P02-T09 — QR Block

## هدف
بلوک QR برای لینک/تماس/نقشه/پروفایل؛ رندر در preview و PDF.

## پیش‌نیاز
- Block registry Core

## پرامپت اجرا

```
طبق Component QR عمل کن (Nest/Next).

تسک: بلوک QR Code را Full-Stack به registry و editor اضافه کن.

الزامات:
1) تحلیل + تسک‌لیست.
2) تولید QR سمت سرور یا کلاینت — یکی را قفل کن؛ برای PDF باید در HTML canonical بیاید.
3) فیلدهای target type (url، phone، email، map، custom).
4) schema + UI تنظیمات؛ i18n/theme؛ docs.
5) Dynamic QR مقصد (redirect) را اگر خارج از Scope است Non-goal اعلام کن یا فاز بعد.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
