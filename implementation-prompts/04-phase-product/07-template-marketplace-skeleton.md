# P04-T07 — اسکلت Template Marketplace

## هدف
زیرساخت انتشار/نصب قالب بین Businessها یا کاتالوگ سراسری SAAS — بدون کامل کردن اقتصاد کامل مگر آماده باشید.

## پرامپت اجرا

```
طبق Template Marketplace به‌صورت Skeleton عمل کن؛ Core را نشکن.

تسک: اسکلت Marketplace قالب را Full-Stack پیاده کن.

الزامات:
1) تحلیل + تسک‌لیست؛ Edition gate (عمدتاً SAAS).
2) مدل catalog templates (سراسری) + install به Business (کپی template).
3) UI مرور/نصب مینیمال؛ docs؛ entitlement.
4) پرداخت قالب را Non-goal یا stub اعلام کن اگر خارج از Scope است و در rules بنویس.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
