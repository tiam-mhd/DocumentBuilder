## هدف
انتشار پروفایل وب از همان Data/Template با مسیر عمومی.

## پرامپت اجرا

```
طبق Publish as Web عمل کن — همان Data؛ رندر HTML عمومی.

تسک: Web Publish را Full-Stack پیاده کن.

الزامات:
1) تحلیل + تسک‌لیست.
2) وضعیت published وب؛ route عمومی Next یا Nest render؛ SEO پایه.
3) همگام با زبان سند و RTL/LTR.
4) Permission Publish؛ docs؛ تم عمومی می‌تواند از brand tokens سند پیروی کند.
5) PDF و Web هر دو از یک منبع حقیقت.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
