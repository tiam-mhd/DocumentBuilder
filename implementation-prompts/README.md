# پرامپت‌های پیاده‌سازی Visual Document Builder

این فولدر نقشهٔ کامل اجرای پروژه تا نسخه نهایی است. هر فاز یک پوشه دارد؛ هر تسک یک فایل `.md` با **پرامپت آماده‌کپی** برای Agent.

## نحوه استفاده

1. قوانین `.cursor/rules/` و `AGENTS.md` را باز بگذارید (alwaysApply هستند).
2. فایل تسک را باز کنید و بخش **«پرامپت اجرا»** را عیناً به Agent بدهید.
3. منتظر پاسخ با وضعیت `تموم شد` یا `تموم نشد` + مرحله بعدی بمانید.
4. ترتیب شماره فایل‌ها را رعایت کنید مگر وابستگی دیگری در خود فایل ذکر شده باشد.

## استک قفل‌شده

**NestJS** · **Next.js** · **PostgreSQL** · **Redis** · **MongoDB** (+ S3-compatible، Chromium PDF)

## قرارداد پرامپت‌ها

هر پرامپت از Agent می‌خواهد:

- قوانین پروژه را بخواند و رعایت کند
- قبل از کد: تحلیل + تسک‌لیست
- **DB (PG/Redis/Mongo به‌قدر نیاز) + NestJS + Next.js** را برای همان بخش هماهنگ بسازد
- در صورت کشف قانون سراسری: اول `.cursor/rules/` را آپدیت کند
- تغییر API → `docs/api/` را به‌روز کند
- تم دارک/لایت و i18n `fa`/`en` را رعایت کند
- پایان پیام: `تموم شد` یا `تموم نشد` + مرحله بعدی
