# P05-T05-04 — کتابخانهٔ Presetهای چیدمان

## هدف
کاربر با یک کلیک چیدمان‌های رایج بسازد: ۲ستونه مساوی، ۲ستونه ۷۰/۳۰، ۳ستونه، نوار+محتوا و … — درج به‌صورت row معتبر در صفحهٔ فعال با undo.

## پیش‌نیاز
- UI ستون‌ها (۰۲) و parity preview (۰۳ ترجیحی)
- پالت یا منوی «چیدمان‌ها» در left rail / empty state

## دامنه Full-Stack
- Frontend: `layout-presets.ts` دادهٔ خالص + UI picker
- Schema: فقط مصرف؛ preset باید بعد از parse معتبر باشد
- i18n نام/توضیح presetها
- Docs UX کوتاه اختیاری

## معیار تموم شدن (DoD)
- [ ] حداقل ۵ preset مستند
- [ ] درج با یک کلیک/درگ؛ انتخاب row جدید
- [ ] پیش‌نمایش شماتیک کوچک در picker (CSS ساده نه تصویر سنگین اجباری)
- [ ] entitlement لازم ندارد فراتر از writable
- [ ] empty canvas CTA «از یک چیدمان شروع کنید»
- [ ] fa+en؛ تم‌ها

## پرامپت اجرا

```
طبق schema ستون‌ها و صفحه‌ساز UX عمل کن.

تسک: کتابخانهٔ preset چیدمان را در ادیتور اضافه کن.

الزامات:
1) تحلیل + تسک‌لیست؛ presetها را به‌صورت factory روی BlockNode[] بساز (idهای تازه).
2) حداقل: 50/50، 30/70، 70/30، 33/33/33، تک‌ستون تمام‌عرض (یا معادل مفید).
3) UI: بخش «چیدمان‌ها» در Palette یا تب جدا left rail — شلوغ نکن.
4) هر preset می‌تواند یک text placeholder سبک داخل columns داشته باشد تا خالی نماند (قابل حذف).
5) undo یک entry برای کل درج.
6) i18n نام‌ها («دو ستون مساوی» / «Two equal columns»).
7) با bodyLock سازگار.
8) marketplace قالب را اینجا نساز.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
