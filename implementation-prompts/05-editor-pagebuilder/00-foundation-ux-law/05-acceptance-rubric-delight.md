# P05-T00-05 — معیار پذیرش «عشق‌وحال» و چک‌لیست کیفی صفحه‌ساز

## هدف
یک روبریک قابل‌اندازه‌گیری برای کیفیت UX صفحه‌ساز بنویسید تا فازهای بعدی و فاز QA (`09`) بدانند «تموم شد» یعنی چه — فراتر از «فیچر هست».

## پیش‌نیاز
- `01`…`04` همین فاز (rule، دو ADR، IA)
- `00-vision-and-gap-analysis.md` بخش پیشنهادهای تحلیل

## دامنه Full-Stack
- فقط Docs: `docs/qa/editor-pagebuilder-delight-rubric.md`
- ارجاع از overview فاز 00 و فاز 09
- اختیاری: یک ردیف در `docs/qa/` ایندکس اگر وجود دارد

## معیار تموم شدن (DoD)
- [ ] روبریک با ابعاد امتیاز (مثلاً 1–5) و آستانهٔ قبول
- [ ] سناریوهای طلایی کاربر (حداقل ۵)
- [ ] چک‌لیست کیفی: سرعت ادراک‌شده، وضوح کنترل‌ها، خطاها، RTL، تم تاریک/روشن، a11y پایه
- [ ] معیارهای منفی (چه چیزی فوراً رد می‌کند)
- [ ] نگاشت هر بُعد به فاز پیاده‌سازی مسئول
- [ ] بدون کد

## پرامپت اجرا

```
طبق پک 05 و اسناد IA/ADR/rule همین فاز عمل کن. فقط مستند QA/روبریک.

تسک: روبریک پذیرش عشق‌وحال صفحه‌ساز را بنویس.

الزامات:
1) فایل `docs/qa/editor-pagebuilder-delight-rubric.md` ایجاد کن.
2) ابعاد امتیازدهی حداقل:
   - Discoverability (پیدا کردن ابزار بدون آموزش)
   - Fluidity (DnD، undo، autosave، بدون جلق)
   - Clarity of properties (کاربر می‌فهمد هر فیلد چه می‌کند)
   - Output confidence (HTML + PDF preview قبل از انتشار)
   - Visual polish (تم، فاصله‌ها، motion هدفمند، paper frame)
   - Trust & safety (قفل‌ها، entitlement، بدون از دست رفتن کار)
   - Inclusive UX (fa/en، RTL، keyboard، reduced-motion)
3) برای هر بُعد: تعریف نمره 1 / 3 / 5 با مثال عینی داخل محصول VDB.
4) آستانهٔ خروج پک پیاده‌سازی: مثلاً میانگین ≥ 4 و هیچ بُعدی < 3؛ به‌علاوه صفر بودن «معیارهای رد فوری».
5) معیارهای رد فوری (نمونه‌ها را کامل کن):
   - PDF روی keystroke
   - JSON/schema خام در UI اصلی ادیتور
   - از دست رفتن edit بدون پیام بعد از خطا
   - شکستن RTL در canvas برای locale=fa
   - پیش‌نمایش PDF بدون rate/entitlement فکر
6) حداقل ۵ سناریوی طلایی end-to-end به زبان کاربر، مثلاً:
   - ساخت بروشور A4 دو ستونه با لوگو و متن
   - تنظیم حاشیه و دیدن قاب کاغذ
   - پیش‌نمایش HTML سپس PDF سپس برگشت به edit
   - قفل بودن سند published و مسیر reopen
   - افزودن بلوک قفل‌شده ماژول و دیدن CTA ارتقا
7) جدول نگاشت: بُعد → فازهای 01…08 که باید پوشش دهند.
8) `00-phase-overview.md` فاز 00 و 09 را با لینک به این روبریک به‌روز کن.
9) کد نزن.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
