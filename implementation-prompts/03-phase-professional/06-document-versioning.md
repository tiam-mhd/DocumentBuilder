# P03-T06 — Document Versioning

## هدف
نسخه‌های Document (v1/v2…) با امکان clone و مقایسه متادیتا (diff عمیق UI می‌تواند ساده باشد).

## پرامپت اجرا

```
طبق Versioning عمل کن (PG متادیتا + Mongo snapshot body).

تسک: Versioning اسناد را Full-Stack پیاده کن.

الزامات:
1) تحلیل + تسک‌لیست.
2) مدل versions؛ ایجاد نسخه روی publish یا دستی؛ immutable snapshot.
3) API list/restore/clone؛ UI تاریخچه؛ docs.
4) جلوگیری از بازنویسی خاموش نسخه منتشرشده.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
