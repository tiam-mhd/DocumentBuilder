# P03-T02 — Data Binding پیشرفته + فرمول ساده

## هدف
Bindingهایی مثل `{{business.name}}`، حلقه‌ها، و فرمول‌های ساده count/filter.

## پرامپت اجرا

```
طبق Dynamic Data Binding عمل کن؛ موتور را امن و محدود نگه دار (بدون eval دلخواه).

تسک: Binding پیشرفته و فرمول‌های ساده را در schema + renderer پیاده کن.

الزامات:
1) تحلیل + تسک‌لیست؛ فهرست توابع مجاز (count، where status=) را قفل کن.
2) پارسر امن در Nest (و/یا shared package) برای preview و PDF یکسان.
3) UI درج فیلد Binding در editor.
4) تست‌ها؛ docs/schema.
5) اگر قانون سراسری expression دیدی در rules بنویس.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
