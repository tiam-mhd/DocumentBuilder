# P03-T09 — Audit Log UI

## هدف
نمایش AuditEventهای مهم (login، business، payment، export، delete) برای Owner.

## پرامپت اجرا

```
طبق Audit عمل کن؛ رویدادها از قبل باید در Core تا حدی نوشته شده باشند — کاملشان کن و UI بساز.

تسک: Audit Log قابل مشاهده را Full-Stack تمام کن.

الزامات:
1) تحلیل + تسک‌لیست؛ فهرست event typeهای اجباری را قفل کن.
2) اطمینان از ثبت رویدادهای Billing/Export/Auth/Business.
3) API لیست فیلتردار + UI؛ i18n؛ docs.
4) عدم نمایش cross-business.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
