# P03-T04 — Interactive PDF

## هدف
PDF با لینک داخلی/خارجی، bookmark، و metadata پایه.

## پرامپت اجرا

```
طبق Interactive PDF عمل کن (Chromium pipeline موجود).

تسک: لینک‌ها و Bookmark را در Export PDF پیاده کن.

الزامات:
1) تحلیل + تسک‌لیست.
2) element link (internal anchor / external / email / phone).
3) TOC و سرفصل‌ها → PDF outline/bookmarks در صورت پشتیبانی موتور — وگرنه ADR محدودیت.
4) تست کلیک‌پذیری؛ docs.
5) UI تنظیم لینک در editor.

پایان: تموم شد یا تموم نشد + مرحله بعدی.
```
