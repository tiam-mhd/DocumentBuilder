# P03-T11 — Spike اختیاری DOCX/PPTX

## هدف
ارزیابی فنی خروجی DOCX/PPTX؛ یا اعلام Non-goal رسمی در rules اگر ارزش ندارد.

## پرامپت اجرا

```
طبق Phase discipline عمل کن — این تسک Spike است نه تعهد تولید کامل.

تسک: Spike دو‌روزه برای DOCX و/یا PPTX از روی Document JSON.

الزامات:
1) تحلیل گزینه‌های کتابخانه و کیفیت RTL فارسی.
2) PoC کوچک یا گزارش «Won't برای نسخه فعلی» با دلیل.
3) اگر Won't: آپدیت `.cursor/rules/` / overview فاز با Non-goal.
4) اگر Go: فقط اسکلت adapter پشت ExportModule؛ کامل‌سازی را تسک‌های بعدی جدا کن.

پایان: تموم شد (با تصمیم Go/Won't صریح) یا تموم نشد + مرحله بعدی.
```
